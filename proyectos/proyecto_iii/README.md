# Proyecto III — Desarrollo End-to-End (40 %)

**Temas:** 1–5  
**Presentación del enunciado:** 20 de octubre de 2026  
**Release Candidate:** 17 de noviembre de 2026  
**Exposiciones:** 1 y 8 de diciembre de 2026

## Objetivo

Diseñar, implementar, probar y desplegar una **solución completa** de datos e IA:

```text
Ingesta → Procesamiento → Servicio de IA → API/App → Despliegue → Monitorización básica
```

Puede ser una API, un cuadro de mando, o una aplicación que combine ambos.

## Requisitos mínimos

1. Arquitectura modular y README claro.
2. Procesamiento de datos real (CSV, API pública o dataset propio).
3. Integración con IA (proveedor o mock justificado + interfaz lista para producción).
4. Pruebas automatizadas y evidencia de CI (GitHub Actions u otro).
5. Despliegue accesible **o** empaquetado listo con instrucciones verificables.
6. Exposición de **5–7 minutos** + preguntas.
7. Cumplimiento de la política de uso de IA (citas).

## Rúbrica orientativa

| Criterio | Peso |
| --- | --- |
| Complejidad y valor de la solución | 25 % |
| Calidad de código y arquitectura | 20 % |
| Integración datos + IA + API | 20 % |
| Tests, robustez y despliegue | 20 % |
| Exposición y documentación | 15 % |

## Evaluación extraordinaria (referencia)

Si no se supera la ordinaria: aplicación completa (**70 %**) + examen (**30 %**), integrando los mismos bloques competenciales.
