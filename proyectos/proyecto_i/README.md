## Objetivo

Desarrollar una solución en Python que demuestre:

- Estructuras de datos adecuadas
- OOP
- Tratamiento de errores
- Validación y manipulación de datos
- Buenas prácticas y documentación

## Enunciado sugerido

Construye un **pipeline de calidad de datos de ventas** (puedes partir de `Datos/ventas.csv`):

1. Carga y validación con excepciones de dominio.
2. Métricas de negocio (importe por región/producto).
3. CLI usable (`python -m ...`).
4. README + docstrings.

## Entrega

- Repositorio GitHub (o carpeta en el repo de la asignatura).
- README con instrucciones de ejecución.
- Código sin secretos.
