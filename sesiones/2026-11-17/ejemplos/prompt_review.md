# Prompt de code review (IA)

```text
Revisa el siguiente código de una API/pipeline de datos+IA.
Centra la review en:
1) secretos y fugas de datos
2) validación de inputs
3) timeouts / reintentos
4) manejo de errores y códigos HTTP
5) complejidad / funciones demasiado largas

Devuelve hallazgos con severidad: crítico | mayor | menor | ruido.
No reescribas archivos enteros; propone cambios mínimos.

«pegar fichero o diff»
```
